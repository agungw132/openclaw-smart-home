# Security Baseline

## Required Controls
- No plaintext secrets in repository.
- Runtime secret injection only.
- Principle of least privilege for service access.
- TLS/secure transport on external exposure.
- Baseline review before promotion beyond DEV.

## Release Security Checklist
- [ ] Secrets scanning clean
- [ ] Access/RBAC review complete
- [ ] External exposure reviewed
- [ ] AppSec sign-off for major security changes
